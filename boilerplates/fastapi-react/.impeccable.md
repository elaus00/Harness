## Design Context

### Users
사용자가 개인 작업을 효율화하며, 새 프로젝트에 재사용할 Harness를 만든다.

### Use cases
이메일·비밀번호로 로그인하고 프로젝트별 업무를 만들고 상태를 관리한다.

### Brand Personality
명확함, 정돈됨, 신뢰감. 사용자가 지정한 Jira/Atlassian을 참조한다.

### Aesthetic Direction
밝은 워크스페이스, 파란 강조색, 좌측 탐색과 밀도 있는 업무 테이블, 적은 장식.

### Design Principles
정보와 작업 상태를 먼저 보여준다. 공통 컴포넌트와 의미 기반 토큰을 사용한다. 실제 저장과 오류 복구를 제공한다. 작은 화면에서도 핵심 행동을 유지한다.
