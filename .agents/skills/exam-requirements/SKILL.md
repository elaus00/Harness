# 현장 요구사항 정리

원본 README와 공식 양식은 읽기만 한다. 요구사항마다 REQ ID, 원문 항목·위치, 수용 기준, 검증 방법을 docs/PRD.md에 기록한다. 기능뿐 아니라 입출력, 역할, 실행 디렉터리, 시간·자원 제한, 제출물·평가 조건을 확인하며 설명·예시·필수 조건을 구분한다.

확인한 사실은 F, 선택한 구현은 D, 미확인 전제는 A ID로 docs/DECISION.md에 기록한다. 명시되지 않은 기준·가중치·권한을 필수화하지 않는다. 모호한 항목은 담당자 질문과 가정 후보로 남기고 독립적으로 가능한 작업을 이어간다.

REQ ID를 docs/TASKS.md의 구현·검증 작업과 연결하고 STATUS에 목표·다음 행동을 적는다. 새 문서는 INDEX에 등록한다. 초기 0~10분은 권장 배분이며 읽지 않은 요구사항을 확인했다고 쓰지 않는다. 조사는 질문·결정 ID에 연결할 때만 15분 이내로 한다. 이 스킬은 반입 규정 확인이나 사용자의 승인을 대신하지 않는다.
