# Clear with Lessons

다음 세션에서 같은 실패를 반복하지 않고 작업을 이어갈 수 있도록 기록한다. 교훈은 재사용할 지식이고, 인계는 현재 작업 상태다. 교훈이 없어도 필요한 인계는 남긴다.

## 적용 범위와 경로

- 사용자 요청과 현재 작업 폴더를 기준으로 대상 프로젝트 루트를 확인한다. 스킬 설치 폴더를 대상 프로젝트로 간주하지 않는다. 대상이 불명확하면 임의의 상위 폴더에 기록하지 말고 경로를 확인한다.
- 프로젝트의 `AGENTS.md`, 문서 색인(`docs/INDEX.md` 또는 `docs/index.md`), 기존 교훈·요청·인계 문서를 먼저 살펴보고 기존 경로와 형식을 따른다. 여기서 제시하는 경로는 프로젝트에 별도 관례가 없을 때의 기본값이다.
- 기존 `docs/insights/`를 교훈 저장소로 쓰고 있다면 유지한다. 신규 프로젝트는 `docs/lessons/`를 사용한다. 두 경로가 모두 있으면 인덱스와 프로젝트 지침에서 쓰는 경로를 선택하고 저장소를 중복 생성하지 않는다.
- 날짜는 사용자의 시간대를 기준으로 적는다. 기록에는 비밀키, 토큰, 인증 정보, 불필요한 개인정보를 포함하지 않는다.

## 회고와 교훈

이번 작업에서 실제로 관찰한 실패, 대처, 결과, 반복 가능한 발견을 검토한다. 다음 기준 중 하나를 충족하는 내용만 교훈으로 저장한다.

- 실패 원인을 확인하고 해결하는 과정에서 얻은 비자명한 지식.
- 반복 가능성이 높은 함정과 이를 알아보거나 피하는 방법.
- 기존 문서에 없는 도구·API·프레임워크 동작이나 설계에 영향을 주는 발견.

단순한 변경 내역, 당연한 사실, 근거 없는 일반화는 교훈으로 만들지 않는다. 원인이 불확실하면 **추정**으로 표시한다. 우회책은 **임시 우회**라고 명시하고 남은 제약을 적는다. 관찰한 사실과 검증한 결과를 가설에서 구분한다.

관련 교훈을 먼저 찾아 같은 문제·같은 적용 범위라면 기존 문서에 새 근거와 결과를 보완한다. 결론이 바뀌면 이전 결론과 변경 이유가 드러나게 수정한다. 별개의 교훈일 때만 `YYYY-MM-DD_주제.md`를 만든다. 같은 파일명이 이미 있으면 내용을 확인하고 갱신하거나 주제를 구별하는 이름을 사용하며 무관한 기록을 덮어쓰지 않는다.

교훈에는 필요한 만큼 다음을 담는다.

- 상황과 적용 범위: 관련 도구·버전·환경 등 재현에 필요한 조건.
- 실패 또는 발견, 확인 가능한 근거: 관련 파일, 명령의 결과, 문서 링크.
- 원인: 확인된 사실과 추정의 구분.
- 시도한 대처와 결과: 해결 여부, 임시 우회 여부, 남은 불확실성.
- 다음에 적용할 방법: 같은 상황을 식별하는 신호와 재발 방지 행동.

새 교훈도 기존 교훈의 수정 사항도 없으면 교훈 파일이나 빈 교훈 디렉토리를 만들지 않는다.

## 사용자 조치

사용자가 직접 해야 하는 미완료 조치가 실제로 있을 때만 `docs/request.md`를 만들거나 갱신한다. 에이전트가 수행할 수 있는 일반 후속 작업은 인계 상태에 기록한다.

- 기존 항목과 중복되는지 확인하고 같은 요청은 갱신한다.
- 새 요청은 제목과 문서 설명을 보존한 채 요청 목록의 최상단에 추가한다.
- 날짜, 짧은 맥락, 구체적인 행동과 완료 기준을 체크리스트로 적는다. 예: `## YYYY-MM-DD — 작업 맥락` 아래에 `- [ ] 사용자가 수행할 조치`.
- 조치가 끝났다는 근거가 있을 때만 완료 처리한다. 새 조치가 없다는 이유로 기존 미해결 요청을 지우거나 완료 처리하지 않는다.

## 현재 상태 인계

현재 상태(`docs/STATUS.md` 또는 `docs/status.md`)의 해당 작업 상태를 최신 정보로 갱신한다. 이미 동등한 인계 문서가 있으면 그 문서를 사용한다. 교훈을 억지로 만들거나 세션 대화 전체를 복사하지 않고 다음 세션에 필요한 사실만 남긴다.

- 이번에 완료한 범위와 주요 결과물의 링크.
- 실제로 수행한 검증과 그 결과. 하지 못한 검증은 미실시로 표시.
- 남은 작업, 장애 요인, 해결되지 않은 질문.
- 다음에 할 구체적인 행동. 완료된 작업이면 남은 작업이 없다고 명시.
- 사용자 조치가 있으면 요청 문서의 해당 항목 링크.

기존 섹션과 다른 작업의 기록은 보존한다. 현재 상태와 충돌하는 과거 내용만 해당 범위에서 정리하고 갱신 날짜를 남긴다. 사용자가 중단을 요청했다면 인계 기록을 위해 새로운 본작업이나 추가 검증을 시작하지 않는다. 사용자가 파일 변경까지 멈추라고 했다면 저장하지 않고 대화로만 인계한다.

## 문서 인덱스와 마무리

- 생성·이동·변경한 문서에 대해 문서 색인(`docs/INDEX.md` 또는 `docs/index.md`)의 해당 항목만 증분 갱신한다. 기존 항목과 섹션, 사람의 설명을 보존하고 같은 링크를 중복 추가하지 않는다.
- 인덱스가 없다면 이번에 저장한 문서의 링크와 한 줄 용도를 담아 만든다. 기존 문서 체계를 전면 재구성하지 않는다.
- 링크는 문서를 기준으로 한 일반 Markdown 상대 링크를 사용하고 대상 파일이 존재하는지 확인한다. 문서 상태나 경로가 바뀌지 않았다면 불필요하게 인덱스를 수정하지 않는다.
- 저장한 교훈, 인계 상태, 남은 사용자 조치를 간결하게 알리고 실제 파일 링크를 제공한다. 교훈이 없다면 “이번 세션에서 별도로 저장할 교훈은 없습니다.”라고 알린다.

이 스킬은 교훈을 `AGENTS.md`의 상시 규칙으로 자동 승격하지 않으며 `MEMORY.md`를 갱신하지 않는다. 반복 근거와 적용 범위가 충분한 규칙 후보는 제안으로만 남긴다.

이 스킬 자체는 세션 종료 훅이 아니다. `/clear`, 대화 아카이브, 앱 종료, 자동 훅 설치·실행을 수행하지 않는다. 문서를 저장한 결과만 알리며, 컨텍스트가 이미 초기화되었거나 세션이 자동 종료되었다고 주장하지 않는다.
