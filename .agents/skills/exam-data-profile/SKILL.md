# 데이터 프로파일

원본 파일을 수정하지 않는다. 동봉 polars/SKILL.md와 작업별 참조를 먼저 읽는다. 인코딩·구분자·헤더·날짜 형식·Polars 버전을 확인한다.

파일별 행 의미, 실제 컬럼·자료형, 행 수, 키 후보·중복·결측, 값 범위·단위·시간대를 확인한다. 행 의미와 키 후보는 README 근거와 추정을 구분한다. 파일 간 조인 키의 자료형·미매칭·고아 참조·행 증식을 확인하고 조인 전후 행 수와 주요 집계를 비교한다.

scan_*·lazy API로 필요한 컬럼·필터·집계를 하나의 계획으로 구성한다. 중간 collect와 Python 행별 함수를 최소화하고 큰 출력에는 버전에 맞는 스트리밍·sink를 검토한다. LazyFrame을 결과 캐시나 최종 메모리 제한으로 간주하지 않는다.

F ID와 재현 명령·파일을 연결하고 샘플 검사는 샘플이라고 표시한다. docs/research/에 결과를 저장하고 INDEX에 참고 상태로 등록한다. 마지막에 담당자 질문과 가정 후보를 각각 적는다. 관측 범위를 도메인 제약·권장 가중치로 확정하지 않는다. 10~30분은 권장 배분이며 외부 조사는 질문·결정 ID별 15분 상한을 따른다.
