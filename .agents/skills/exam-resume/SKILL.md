# 중단 지점에서 복귀

원본 README와 작업 디렉터리를 확인한다. clone 보관 디렉터리를 응시 루트로 혼동하지 않는다. docs/INDEX.md, DECISION.md, STATUS.md, TASKS.md를 읽되 기존 관례가 다르면 실제 경로를 따른다.

실제 변경·미커밋 파일·실행 프로세스·작업 ID를 읽기 전용으로 확인한다. 다른 세션과 사용자 변경을 보존한다. 마지막 검증의 명령·결과·시점 이후 파일이 바뀌었으면 현재 성공으로 간주하지 않는다.

현재 REQ ID·확정 결정·열린 질문과 가정·다음 작업 하나를 짧게 정리하고 이어간다. 이미 합의한 범위를 반복 승인받지 않는다. 종료 회고가 없어도 파일과 검사 근거로 복귀한다.

생성 잠금은 다른 프로세스 실행 여부를 확인하기 전 해제하지 않는다. 복구 명령은 관련 실행을 멈춘 뒤에만 쓴다. 모르는 사실과 사용자 조치가 필요한 항목만 질문한다.
