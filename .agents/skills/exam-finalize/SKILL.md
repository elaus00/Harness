# 제출 문서 마무리

README·공식 양식·DECISION·STATUS·TASKS를 읽는다. 마지막 30분은 권장 배분이다. 공식 파일을 새로 만들거나 덮어쓰지 않는다.

HOW_TO_RUN에 실제 디렉터리·환경·설정 이름·명령·이용 순서·검증·제약을 공식 순서로 적는다. 비밀값·실행하지 않은 성공 주장은 넣지 않는다. Docker는 사용자가 실제 과제 지정 디렉터리에서 확인한 구성·명령만 기록하며 하네스 반입을 Docker 검증으로 쓰지 않는다.

AI_COLLABORATION은 현장 공식 파일이 있을 때 그 양식을 기준으로 작성안을 준비한다. 없으면 docs/research/submission-draft.md에 초안을 두고 INDEX에 참고로 등록한다. 공식 파일 반영은 사용자 지시를 따른다. 실제 AI·스킬·사전 반입 코드·담당 작업·사람이 검토한 범위를 기록하고 허용 여부·세션 사용을 지어내지 않는다.

PRD 수용 기준과 실제 테스트·독립 검증 결과를 대조한다. 미구현·미실행·위반을 숨기지 않는다. humanizer-ko로 산문을 다듬되 사실·수치·인용·확신도를 보존한다. STATUS·TASKS·INDEX를 갱신한다. 이 스킬은 제출·전송·배포 권한을 부여하지 않는다.
