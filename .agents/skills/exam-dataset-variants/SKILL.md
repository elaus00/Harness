# 데이터셋 변형

README·확정 계약·프로파일을 읽고 표 변환에는 동봉 Polars 스킬과 참조를 적용한다. datasets/original/의 출처·해시를 기록하고 원본은 수정하지 않는다.

정상 변경은 계약을 보존하는 범위에서 선택해 valid/에 저장한다. 중복·삭제·수치 변화가 항상 정상이라고 가정하지 않는다. 오류본은 invalid/에 가능한 한 한 규칙씩 위반하게 만들고 복합 위반은 구분한다.

사례마다 변경·관련 REQ/F/D/A ID·기대 판정·오류 위치를 기록한다. 난수 seed·절차를 남기고 원본·결과의 행 수·키·주요 집계를 확인한다. 스키마 변경은 계약 변경인지 입력 오류인지 구분하며 원문에 없는 경계는 가정 후보로 남긴다.

독립 validator의 실측 판정과 기대 판정을 비교한다. 검증기가 없으면 미검증으로 표시한다. 목록을 INDEX에 연결하고 실제 데이터 적용은 검증·원자적 적용 절차를 거친다.
