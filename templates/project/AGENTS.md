# {{PROJECT_NAME}} 작업 규칙

- 시작할 때 `docs/index.md`와 `docs/status.md`를 읽고 관련 문서만 추가로 확인한다.
- 목표와 완료 기준이 정해졌으면 일상적인 구현 선택은 자율적으로 진행한다. 이미 승인된 범위를 반복 확인하지 않는다.
- 큰 기능·설계 변경에는 brainstorming을, UI 품질 개선에는 Impeccable을 사용한다. 기존 설치 여부부터 확인한다.
- 프로젝트의 실제 설정과 문서에서 실행·검증 명령을 확인한다. 확인하지 않은 명령을 가정하지 않는다.
- 변경과 관련된 검증을 실행하고 결과·미실행 항목을 보고한다.
- 문서 추가·이동·폐기 시 `docs/index.md`를 갱신한다.
- 의미 있는 작업 완료 또는 종료 요청 시 `.agents/skills/clear-with-lessons/SKILL.md`를 적용한다.
- 사용자 변경 사항을 보존하고 템플릿 업데이트를 일괄 덮어쓰지 않는다.

프로젝트별 기술·명령·제약은 확인되는 대로 기존 문서 또는 `docs/workflow.md`에 기록한다.
