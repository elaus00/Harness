# {{PROJECT_NAME}} 작업 흐름

## 시작

기존 AGENTS.md, 문서 색인, 현재 상태를 읽는다. 실제 기술 구성과 실행·테스트 명령은 저장소 설정에서 확인해 이 문서에 기록한다. 아직 확인하지 않은 명령은 실행 가능한 명령으로 적지 않는다.

## 실행과 검증

작업 규모에 맞는 짧은 계획을 세우고 구현한다. 변경에 관련된 검증을 실행하며 실패와 미실행 항목을 보고한다. 기존 사용자 변경과 프로젝트 관례를 보존한다.

## 종료

clear-with-lessons로 교훈과 다음 작업 상태를 구분해 남긴다. 교훈이 없으면 새 교훈 파일은 만들지 않는다. 사용자 조치가 실제로 필요할 때만 `request.md`를 추가하고 색인에 연결한다. 세션 초기화는 자동으로 실행하지 않는다.
