# 인증과 Jira 스타일 대시보드

상태: 완료 (2026-11-05).

## 구성

기존 FastAPI·React·Vite 기본형에 이메일·비밀번호 인증, SQLite 영속 저장, HttpOnly 세션 쿠키를 추가했다. Jira/Atlassian 토큰을 실제 설치하고 로컬 UI 컴포넌트·상단 메뉴·좌측 탐색·프로젝트·업무 테이블을 구성했다.

사용자별 업무 생성·상태 변경, 검색·필터·실제 활동 기록을 연결했다. 새 계정은 비어 있으며 샘플 추가를 선택하면 예시 업무 7개를 생성한다.

## 검증

- API 테스트 11개: 비밀번호 해시, 세션 교체·만료·폐기, 중복 계정, 요청 출처, rate limit, 업무 소유권, 샘플 중복 방지, health.
- 실제 브라우저: 가입 → 샘플 → 생성 → 수정 → 검색 → 새로고침 → 모바일 → 로그아웃 → 잘못된 비밀번호 → 로그인.
- lint·타입 검사·프로덕션 빌드.

## 범위

[인증·저장·운영 전제](../../boilerplates/fastapi-react/README.md)와 [디자인 시스템](../../boilerplates/fastapi-react/DESIGN_SYSTEM.md)을 따른다. 이메일 검증·비밀번호 재설정·SSO·팀 권한은 후속 확장이다.

최종 `make check`와 `make e2e` 통과. 데스크톱·모바일 캡처를 직접 확인했다. SQLite 스레드 제약 문제는 연결과 dependency 종료 범위를 수정한 뒤 같은 브라우저 흐름으로 재검증했다.
