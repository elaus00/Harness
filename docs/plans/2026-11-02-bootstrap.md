## 완료 기준

- [x] 짧은 AGENTS.md와 문서 색인·작업 흐름·상태 문서가 연결된다.
- [x] 프로젝트 템플릿과 회고 스킬을 사용할 수 있다.
- [x] 기존 스킬의 실제 설치 위치와 출처를 기록한다.
- [x] 적용 전 미리보기에서 대상 파일이 변경되지 않는다.
- [x] 재적용 시 사용자 문서와 기존 스킬을 보존한다.
- [x] 경로 충돌과 심링크를 통해 다른 위치에 쓰지 않는다.
- [x] 문서 링크와 스킬 형식을 검증하고 결과를 기록한다.

## 작업 단위

1. 기본 문서와 프로젝트 템플릿 작성 → 링크와 내용 일관성 확인.
2. 기존 clear-with-insight를 Codex 스킬로 이식 → 형식 검사와 행동 범위 검토.
3. 설치 상태 기록 → 실제 SKILL.md 존재와 파일 해시 확인.
4. 적용 도구 작성 → 임시 폴더에서 미리보기·적용·재적용·경로 충돌 검증.
5. 상태와 색인 갱신 → 사용 방법과 남은 선택 보고.

검증 결과는 완료 시 이 문서에 남긴다. 작업 단계는 writing-plans의 분해 원칙을 참고한 로컬 간소화 구성이다.
