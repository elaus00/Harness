# 0001: 공통 원본과 프로젝트 적용을 분리

- 날짜: 2026-11-02
- 상태: 채택
- 근거: 사용자가 별도 Harness 폴더에서 공통 템플릿을 관리하고 프로젝트별로 적용하는 선택지를 선택했고 후속 진행을 요청했다.

## 결정

`/Users/elaus/Projects/Harness`에서 공통 문서와 템플릿을 관리한다. 프로젝트마다 필요한 파일을 복사하고 기존 규칙은 검토 후 병합한다. 전역 규칙을 자동 변경하거나 기존 프로젝트 전체에 일괄 적용하지 않는다.

## 비교

- 전역 규칙만 관리: 간단하지만 프로젝트별 맥락과 검증 명령을 담기 어렵다.
- 프로젝트마다 독립 작성: 유연하지만 같은 개선 사항을 반복 적용해야 한다.
- 공통 원본 + 프로젝트 적용: 공유 기준을 유지하면서 프로젝트별 차이를 보존한다. 업데이트를 선택적으로 병합해야 하는 비용은 감수한다.

## 범위

기본 문서, 문서 색인, 프로젝트 템플릿, 기존 회고 명령의 Codex 스킬 이식, 스킬 설치 상태 기록과 적용 도구를 포함한다. 전역 Impeccable 마이그레이션, 추가 Superpowers 전체 설치, 자동 종료 훅은 포함하지 않는다.
